## Reproduction

From the repository root, using Python 3.12 and uv 0.12.10:

```bash
uv sync --locked --group qualification
uv run --locked --offline --group qualification python -m qualification --output var/qualification/report.json
uv run --locked --offline --group qualification pytest -q
uv run --locked --offline --group qualification ruff check src tests qualification
uv run --locked --offline --group qualification ruff format --check src tests qualification
uv pip check
```

On this machine use `/home/jack/.local/bin/uv` if uv is absent from PATH. The report command exits nonzero if an invariant fails. It runs two identical corrected backtests, an uncorrected dividend probe, a zero-spread run and an ex-date-entry variant. Each uses the actual engine; checks do not substitute a hand-written matching engine. Model files and engine-generated artifacts live in a temporary child directory and are removed afterward. The JSON report is retained at the requested path. Run without Python's `-O` option because the qualification harness uses assertions.

The engine regression test also supplies dummy inherited secrets, a bogus data-provider override and an enabled-dotenv setting to verify the launcher isolates them. Plain `uv sync --locked` omits the optional engine dependencies; the default suite then reports the engine test as skipped. Such a run verifies the foundation only and does not count as BB-002 qualification.
