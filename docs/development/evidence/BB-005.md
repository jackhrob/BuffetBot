## Material conventions and remaining work

The [market-data guide](../../market-data.md) records the researched API contracts and commands. The implementation uses Python's standard HTTP client directly, preserving decimal parsing and original response bytes without adopting the SDK's float models or adding dependencies.

Daily output aggregates source minutes in `[open, close)`. This excludes extended-hour minutes and closing-boundary auction prints, and it need not match official daily OHLC/volume. The limitation is part of each experiment reference. Historical eligibility at close + 15 minutes and action knowledge at the ex/effective open are explicit exploratory assumptions; their true original publication/revision timestamps are unknown. Actual ingestion timestamps are retained, and prospective context rules remain enforced separately.

Refresh downloads a complete selected range rather than merging partial revisions in place. This is the deliberately simple MVP versioning path; optimizing incremental network fetches is not implemented. No job queue, broker adapter, policy/model workflow, automatic promotion or execution behavior was added.
