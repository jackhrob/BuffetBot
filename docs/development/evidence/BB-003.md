## Verification

The full command used the already locked optional engine group so that BB-002's regression was included:

```bash
uv run --locked --offline --group qualification pytest -q
uv run --locked --offline --group qualification ruff check src tests qualification examples/contracts/validate.py
uv run --locked --offline --group qualification ruff format --check src tests qualification examples/contracts/validate.py
```

**Passed:** 150 tests in 10.54 seconds, including 110 contract cases and all 40 earlier cases. Ruff lint passed; all 20 Python files were formatted. The contract cases include:

- Valid JSON round trips for all required top-level records and a manifest.
- Future observations/adjustments/training cutoffs, mixed timezone representations, naïve timestamps, and exact expiry boundaries.
- Duplicate symbols/records, foreign target symbols, mismatched run/specification/strategy/model references and unsupported order assumptions.
- Wrong currency/percentage/share units, float/bool coercion, nonfinite values, oversubscribed weights and cash/share reservations.
- Exact Unicode source spans, altered document hashes, missing sources and explicit unknown assessment outcomes.
- Cumulative versus incremental partial fills, delayed event recording, uncertain/cancelled outcomes and invalid quantities.
- Stable specification identity under key order, decimal spelling, default expansion and equivalent timezone offsets; changed seeds/data/code/strategy/prompt/costs change the identity.
- Data-only example execution with Python networking denied and no engine/provider/model imports.

A second **fresh temporary environment** was installed from `uv.lock` with `uv sync --locked --offline`, without the qualification group. It ran the example validator and the existing doctor, then confirmed contracts import with Pydantic 2.12.5 while Lumibot and scikit-learn are absent. All commands returned zero. The temporary environment was removed after recording its results. Neither `pyproject.toml` nor `uv.lock` changed in BB-003.

The examples independently verify equity **2070 USD**, spendable cash **780 USD**, all-cash demo weight **1**, and two distinct run IDs with the same specification hash. No files/jobs are created by the manifest factory. [Example records and runner](../../../examples/contracts/README.md) are intentionally synthetic and include illustrative, unresolved artifact identities.

## Limits and next story

This is the validated contract layer, not an execution or storage workflow. Hash syntax/bindings do not establish that a dataset or model blob exists, that supplied metadata is true, or that an LLM interpretation is correct. Snapshot publication, coverage/calendar validation, artifact checksums, concrete policies/risk checks, model evaluation, engine integration and broker lifecycle controls remain in their owning stories. Canonical identity does not create immutable storage by itself; BB-004/006 must enforce publication and job/artifact rules.

BB-003 makes no investment-performance claim and does not advance actual paper broker acceptance. The next story is [BB-004: dataset snapshots, quality checks and offline fixtures](../04-dataset-snapshots.md).
